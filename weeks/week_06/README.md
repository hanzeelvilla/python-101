# Week 6: Introduction to Object-Oriented Programming (OOP)

¡Bienvenido a la Semana 6! En este punto del curso daremos uno de los saltos más importantes en tu carrera como desarrollador: el paso de la programación estructurada a la Programación Orientada a Objetos (POO).

Hasta ahora, tus programas se basaban en escribir funciones sueltas y manipular datos dentro de diccionarios o listas. Con la POO, cambiarás tu mentalidad de diseño: aprenderás a empaquetar los datos (Atributos) y las acciones (Métodos) dentro de estructuras unificadas y reutilizables llamadas Clases. Este paradigma es la columna vertebral del desarrollo de software moderno y te permitirá modelar entidades complejas del mundo real.

## Objetivos de la semana

- Comprender la diferencia fundamental entre una Clase y una Instancia/Objeto (la entidad real en memoria).
- Dominar la sintaxis del método constructor `__init__`, la notación de punto (.) y el uso correcto de `self`.
- Crear Métodos de Instancia para definir comportamientos y modificar el estado interno de los objetos de forma segura.
- Utilizar el método mágico `__str__` para representar objetos de forma limpia e inteligible en la consola.
- Aplicar el concepto de Composición e Interacción entre Clases, aprendiendo a almacenar e invocar objetos dentro de otros objetos.
