# Week 1: Fundamentals of Logic & Control Flow (Part 1)

¡Bienvenidos a la primera semana del curso! El objetivo de estos días es familiarizarnos con la sintaxis de Python, entender cómo la computadora almacena información básica y aprender a controlar el flujo de ejecución de nuestros programas.

---

## Objetivos de la semana

- Declarar y manipular variables utilizando diferentes tipos de datos.
- Interactuar con el usuario a través de la consola (Input/Output).
- Entender la diferencia lógica entre una expresión y una sentencia.
- Implementar estructuras condicionales y ciclos para resolver problemas simples.

---

## Orden de lectura y estudio

Para cubrir todos los temas de esta semana de manera lógica, sigue este orden:

1. **[01_what_is_python.md](./01_what_is_python.md)**
   - Conocerás qué es Python, sus características principales y sus desventajas en la industria.
2. **[02_variables_and_data_types.md](./01_variables_and_data_types.md)**
   - Aprenderás a guardar datos en memoria, comentar tu código y transformar datos de un tipo a otro (casting).
3. **[03_io_and_operators.md](./02_io_and_operators.md)**
   - Veremos cómo pedir información al usuario y cómo realizar operaciones matemáticas y lógicas con esos datos.
4. **[04_expressions_vs_statements.md](./03_expressions_vs_statements.md)**
   - Un concepto clave para entender cómo Python evalúa cada línea de código que escribes.
5. **[05_control_flow.md](./04_control_flow.md)**
   - Aprenderás a usar `if`, `else`, `for` y `while`. Aquí es donde tus programas empiezan a "tomar decisiones".
