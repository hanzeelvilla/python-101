# Week 5: Consolidation, Efficiency & Integration Workshop

Hasta ahora has aprendido a controlar el flujo de un programa, crear funciones y almacenar información en cuatro contenedores completamente diferentes.

Esta semana no añadiremos más estructuras de datos. En su lugar, perfeccionaremos tu forma de escribir código con una herramienta clásica de Python llamada **List Comprehension** (una forma elegante de procesar listas en una sola línea) y nos enfrentaremos a **4 grandes retos integradores**. Estos problemas ya no son mini-ejercicios de 5 líneas; son simulaciones de sistemas reales que te obligarán a conectar todas las piezas del rompecabezas.

## Objetivos de la semana

- Dominar la sintaxis de **List Comprehension** para filtrar y transformar datos de forma compacta.
- Desarrollar la capacidad de desglosar problemas de código extensos y modulares.
- Aprender a anidar e iterar estructuras complejas (listas con diccionarios y colecciones aleatorias).
- Consolidar la confianza al leer errores en la consola y depurar lógica de control avanzada.

## Mapa de Ruta para esta Semana

Organiza tu espacio de trabajo y tu ritmo de desarrollo siguiendo este orden:

### 1. [01_list_comprehension.md](./01_list_comprehension.md)

Una lectura enfocada puramente en la eficiencia visual. Aprenderás a transformar bucles `for` tradicionales con condicionales en expresiones de una sola línea de código sumamente elegantes.

### 2. [02_integration_workshop.md](./02_integration_workshop.md)

El taller central de la semana. Aquí encontrarás **4 proyectos modulares y extensos** diseñados para hacerse en parejas o como retos de portafolio:

1. **The Randomized Trivia Engine:** Un sistema de cuestionarios interactivos con respuestas de opción múltiple (A, B, C, D) que desordena las preguntas aleatoriamente en cada ejecución.
2. **The Smart Inventory Filter:** Un procesador masivo de almacén que utiliza List Comprehension para calcular descuentos y alertas de stock de forma automática.
3. **The Fighter Stats Matcher:** Una simulación que cruza perfiles de personajes anidados para emparejar combates equilibrados basados en rangos de nivel.
4. **The Digital Security Audit:** Un script de ciberseguridad que utiliza Sets para detectar accesos inusuales o sospechosos cruzando bitácoras de servidores.
