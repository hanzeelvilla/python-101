# Week 2: Functions, Scope, and Algorithmic Thinking

En la semana anterior aprendiste a controlar el flujo de un programa de forma secuencial. Esta semana daremos el paso más importante hacia la profesionalización de tu código: **la modularidad**. Aprenderás a empaquetar lógica en funciones reutilizables y a analizar qué tan eficiente es tu código mediante el pensamiento algorítmico.

---

## Objetivos de la semana

- Dominar la creación de funciones: parámetros, argumentos y el valor de retorno.
- Entender la diferencia crítica entre `print()` y `return`.
- Diferenciar entre el alcance (scope) local y global de las variables.
- Introducción a la notación **Big O** para medir la eficiencia de un algoritmo.
- Implementar tu primer patrón de diseño algorítmico: **Two Pointers**.

---

## Orden de lectura y estudio

Sigue este orden para construir tu conocimiento de forma sólida:

1. **[01_functions_basics.md](./01_functions_basics.md)**
   - Aprenderás a definir funciones (`def`), pasar información mediante parámetros y extraer resultados con `return`.
2. **[02_scope_and_builtins.md](./02_scope_and_builtins.md)**
   - Entenderás dónde "viven" tus variables y cómo usar herramientas nativas poderosas como `range()` y la librería `random`.
3. **[03_intro_to_big_o.md](./03_intro_to_big_o.md)**
   - Aprenderás a evaluar la complejidad de tiempo y espacio de tu código de forma conceptual.
